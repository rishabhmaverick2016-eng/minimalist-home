# Minimalist Home (Couple Edition)

A 100% free, distraction-free Android home screen launcher inspired by "minimalist phone". No icons, no subscriptions, zero ads. Built with Kotlin and Jetpack Compose for Android.

## Features
- **Zero Icons, Pure Typography:** Clean text list of your essential favorite apps on the home screen.
- **Mindful 15-Second Delay:** Add a gentle breathing countdown timer before opening tempting apps (Instagram, YouTube, Reddit) to break doom-scrolling habits.
- **Full App Drawer with Fast Search:** Swipe up to view all installed apps alphabetically, with instant search.
- **Couple Personalization:** Customizable mindful mantra / couple note under the clock.
- **Custom App Naming & Hiding:** Rename any app or hide apps you don't want to see.
- **Themes:** OLED Pure Black, Clean Light, and Warm Paper.

## Quick Start: Build & Install on Your Android Phones

1. **Double-click `DEPLOY_GITHUB.bat`** in this folder.
2. Enter your GitHub repository link.
3. GitHub Actions will automatically build the `app-debug.apk` in ~2 minutes.
4. Download the `.apk` on your phone and your wife's phone, install it, and tap your Home button!
